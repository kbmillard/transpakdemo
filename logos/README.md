# TransPak Web Development Assets

Cleaned and exported for Cursor / Next.js / static websites.

## Included
- `full-logo/` — full TransPak wordmark with transparent background
- `mark/` — icon/brand mark with transparent background
- `favicon/` — favicon.ico, PNG favicon sizes, Apple touch icon, Android icons, webmanifest
- `originals/` — original uploaded images

## Recommended usage
```tsx
<img src="/full-logo/png/transpak-logo-full-640.png" alt="TransPak" />
```

```tsx
<img src="/mark/png/transpak-mark-512.png" alt="TransPak mark" />
```
